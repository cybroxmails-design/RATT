1. Executive Summary & Objective

RATT (Rapid Access To Text) is an enterprise-grade multi-slot clipboard acceleration platform designed to overcome the standard OS single-item clipboard bottleneck. Engineered by Cybrox.Inc, RATT enables seamless multi-slot copying, cutting, pasting, live machine translation, and peer-to-peer screen mirroring directly within native Windows application workflows.

Core Value Proposition
Zero-disruption workflow enhancement: Users interact with RATT via two-stroke global keyboard chords (e.g., Ctrl+C followed by a slot digit) or directly from the native Windows Explorer right-click cascading menu. Zero console window flickers, sub-10ms response times, and strictly in-memory data lifetimes ensure privacy and speed.

2. High-Level Layered System Architecture

The system is organized into five decoupled layers ensuring complete isolation between operating system low-level hooks, the application event loop, data manipulation engines, and external web APIs.

Figure 1: Full-Stack Layered Architecture & Inter-Process Communication Flow

1. OS Integration Layer

Direct Win32 bindings: pyperclip for OS clipboard, low-level keyboard hooks via keyboard, system notification area via pystray, and cascading context menu registry trees in HKCU.

2. IPC & Singleton Engine

Local loopback TCP socket (127.0.0.1:47653) with SO_EXCLUSIVEADDRUSE ensures exactly one daemon runs while multiplexing shell actions from RATT.vbs.

3. Central Coordinator

RattApp coordinates the Tkinter root event loop, dynamic frame swapping (via EmbeddedPage pattern), background thread orchestration, and registry state publishing.

4. Business Logic & Crypto

Thread-safe multi-slot buffer (2 to 50,000 slots) backed by ephemeral Fernet AES-256 session keys that are completely destroyed from RAM upon application termination.

5. Security, Memory Safety & Cryptographic Design

Zero Cold-Storage Persistence

Text copied into slots is never written to disk. All slots reside exclusively in volatile memory protected by threading.Lock. Closing the app wipes all data.

Ephemeral Fernet Encryption

Clipboard slots are encrypted in-memory using Fernet AES-256. The session key is generated at boot via Fernet.generate_key() and wiped with destroy() upon exit.

User-Level Registry Scope

All context menu modifications are strictly scoped to HKEY_CURRENT_USER (HKCU). RATT operates with zero Administrator privileges, preventing privilege escalation.

Command Injection Immunity

Arguments passed through RATT.vbs are strictly validated using re.fullmatch(r"[A-Za-z0-9\-]{1,10}", a), guaranteeing shell parameter safety.
